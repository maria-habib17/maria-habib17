## 🔍 CodeSpectra

My final-year project, **CodeSpectra**, is an academic code clone detection system designed to identify different forms of similarity between student programs.

The project explores:

- Type-1 to Type-4 code clone detection
- Function and method-level code comparison
- Program analysis and code normalization
- Machine-learning-assisted similarity analysis
- Evidence-based reporting for instructor review

Working on CodeSpectra has led me to become particularly interested in **code clone detection, program analysis, reproducibility of similarity analysis, and AI for Software Engineering**.
